# Throne — Solas Edition

**Десктопный прокси-клиент на Qt и [sing-box](https://github.com/SagerNet/sing-box) — с тёплыми темами Claude, быстрыми правилами и редактором правил маршрутизации**

Throne — Solas Edition управляет прокси-профилями и подписками, направляет трафик по профилям маршрутизации и работает как системный прокси или в режиме Tun. В этой версии к нему добавлены свои темы оформления и инструменты, чтобы быстро добавлять, менять и удалять правила маршрутизации — в том числе для запущенных программ.

## Возможности Solas Edition

### Темы Claude Dark и Claude Light

Тёплая палитра в стиле Claude: фон `#21201E` в тёмном варианте и `#FAF9F5` в светлом, акцент `#D97757` / `#C96442`. Скруглённые кнопки, поля, меню и вкладки, мягкая подсветка при наведении и фокусе; цвета списка серверов, графиков и лога подстраиваются под тему.

Обе темы — обычные пункты в списке тем в настройках, рядом с остальными: выбранная применяется сразу и сохраняется как любая другая. Если переключиться на другую тему, возвращается системный стиль.

> В прежних версиях была отдельная «Тема Solas» в меню программы. Её больше нет: если она была включена, один раз выберите Claude Dark или Claude Light в настройках.

### Вкладка «Правила»

Нижняя панель → **Правила**. Вкладка сразу открывает правила активного профиля маршрутизации и перечитывает профиль при каждом переходе на неё.

- **Список правил** — таблица «Список · Тип · Значение» со всеми простыми правилами профиля и поиском по ним.
- **Добавить** — тип правила, значение и список (через прокси, напрямую, блокировать, WARP-bypass), затем «Добавить» или `Enter`. Подсказка под формой сразу показывает ошибку в строке, повтор или предупреждение «правило не сработает — его перехватит другое».
- **Из процессов…** — выбор запущенных или недавно подключавшихся программ (или любого файла через «Обзор»), совпадение по имени процесса или по точному пути. Для каждой выбранной программы добавляется правило `processName:` или `processPath:` в список, выбранный в форме, — всё за одно сохранение. Повторы и неверные строки пропускаются и перечисляются в строке статуса.
- **Подсказки при вводе** — для типов правил по процессу поле значения предлагает программы из того же списка.
- **Изменить** — двойной клик по строке или кнопка «Изменить», затем «Сохранить»; `Esc` отменяет.
- **Удалить** — кнопка, клавиша `Delete` или правый клик, с подтверждением. В меню по правому клику правило можно и скопировать.

Если строка уже была в другом списке или у другого сервера, она переносится, а не дублируется.

### Быстрые правила — `Ctrl+R`

Окно для правил активного профиля маршрутизации, открывается по `Ctrl+R` или из меню маршрутизации.

- Тип правила (домен, поддомены, ключевое слово, regex, IP / подсеть, rule-set, процесс), значение и действие: через прокси, напрямую, блокировать, WARP-bypass.
- Та же проверка при вводе и тот же перенос строки из другого списка, что и на вкладке «Правила».
- Списки правил по действиям с правкой целиком.
- Импорт и экспорт профиля маршрутизации: JSON `throne-route-profile` или ссылка `throne://`.

Профили, заданные сырым JSON, защищённые и обновляемые по ссылке или подпиской, ни окно, ни вкладка «Правила» не меняют — причина показывается над формой.

## Скачать

Готовые сборки — на странице [Releases](https://github.com/SolasFor/Throne/releases/latest):

| Система | Файл |
|:--|:--|
| Windows | `Throne-<версия>-windows64.zip` — portable x64, установщик `windows-universal-installer.exe` |
| macOS | `Throne-<версия>-macos-arm64.zip` (Apple Silicon), `macos-amd64.zip` (Intel) |
| Debian / Ubuntu | `Throne-<версия>-debian-amd64.deb` |
| Fedora / openSUSE | `Throne-<версия>-fedora-amd64.rpm` |
| Linux portable | `Throne-<версия>-linux-amd64.zip` |

Portable-версию для Windows достаточно распаковать и запустить `Throne.exe`.

### macOS

Сборки не подписаны, поэтому перед первым запуском снимите карантин: `xattr -d com.apple.quarantine /path/to/Throne.app`. Перенесите `Throne.app` в `/Applications` до первого запуска — иначе может не сработать запрос прав для ядра.

## Протоколы

SOCKS, HTTP(S), Shadowsocks, Trojan, VMess, VLESS, TUIC, Hysteria, Hysteria2, AnyTLS, Mieru, Snell, NaïveProxy, Juicity, TrustTunnel, ShadowTLS, WireGuard, AmneziaWG, MASQUE, SSH, DNSTT / VayDNS, MasterDNS, Xray VLESS (XHTTP / XDRIVE), OpenVPN / OpenConnect, собственные outbound и конфиги sing-box и Xray, цепочки outbound.

Подписки: ссылки, JSON-конфиги sing-box, формат ссылок v2rayN, частично Shadowsocks и Clash.

## Сборка

Сборка идёт в GitHub Actions: Actions → **Throne build matrix** → Run workflow, ветка `dev`, `tag` — номер версии. Пустой `publish` собирает файлы в артефакты запуска, `p` публикует предрелиз, `r` — релиз.

История изменений — в [CHANGELOG.md](CHANGELOG.md).
