# Throne — Solas Edition

Ветка `solas-ui` поверх `dev` из [throneproj/Throne](https://github.com/throneproj/Throne). Каждое изменение — отдельный коммит, сравнение с оригиналом: `dev...solas-ui`.

## Что добавлено

| Что | Где в интерфейсе | Файл |
|---|---|---|
| Тема **Solas** — тёплая палитра в стиле Claude из [SolasFor/nekobox](https://github.com/SolasFor/nekobox): скругления, мягкая подсветка при наведении и фокусе, «таблетки» вкладок | Меню программы → **Тема Solas** (как в системе / тёмная / светлая / выключена) | `include/ui/solas/SolasTheme.hpp` |
| **Быстрые правила** — тип, значение, действие, проверка при вводе, предупреждение «правило перекрыто», списки правил с правкой, импорт и экспорт профиля маршрутизации | `Ctrl+R` или меню маршрутизации → **Быстрые правила…** | `include/ui/solas/QuickRules.hpp` |
| Вкладка **Правила** в нижней панели: **График \| Статистика** совпадений правил по данным ядра | Нижняя панель → **Правила** | `include/ui/solas/RuleStatsTab.hpp` |

Весь новый код — заголовочные файлы без `Q_OBJECT`, подключаемые из `src/ui/mainWindow/mainwindow_icons.cpp`. `CMakeLists.txt`, `.ui` и `.qrc` не тронуты, поэтому ветка легко переносится на свежий `dev`.

## Как это работает

- **Тема** ставится поверх темы Throne (Fusion + палитра + QSS) и переустанавливается после каждой смены темы в настройках. Пока тема Solas включена, выбор темы в настройках Throne не виден — выключите Solas в меню программы. Настройка хранится в `config/solas.ini` рядом с программой.
- **Быстрые правила** пишут в активный профиль маршрутизации тем же путём, что и пункт «добавить правило» в списке соединений: `AppendSimpleRule` → перенос из других списков → `RouteService::Save` (Throne сам отмечает, что маршрутизацию нужно перезапустить). Профили сырого JSON, защищённые, обновляемые по ссылке или подпиской не редактируются.
- **Вкладка «Правила»** считает соединения, трафик и скорость по полям `rule` / `ruleItem`, которые присылает ядро. Данные идут, пока открыта вкладка «Соединения» или «Правила»; галочка **Собирать в фоне** держит сбор и при свёрнутом окне.

## Сборка Windows portable

Actions → **Throne build matrix** → Run workflow → ветка `solas-ui`, `tag` = например `1.4.2-solas`, `publish` оставить пустым. Portable-архив будет в артефактах запуска.
